# 题型识别与模型选型

选模型前先逐小问判定题型。给整道题贴一个标签必然出错；复合题（评价+预测+优化）按小问分别判定。本文件是资料提炼结果，与 `算法索引.md` 配合使用。

## 六大题型判定

| 类型 | 信号词 | 交付物 | 主指标 | 真题示例 |
|---|---|---|---|---|
| 评价 | 评价、排序、优劣、影响程度 | 排名与权重 | 排名稳定性 | 2020C 信誉评级 |
| 判别 | 判别、鉴别、属于已知哪类 | 每个样本标签 | F1、AUC | 2022C 文物归类 |
| 分组 | 分组、划分类型但未给标准 | 分组方案与画像 | 轮廓系数、ARI | 2022C 亚类划分 |
| 预测 | 预测、趋势、未来、影响因素 | 数值与区间 | RMSE、MAE、MAPE | 2023C 未来一周销量 |
| 最优 | 最优、最小、调度、分配、策略 | 决策变量取值 | 目标值、可行性 | 2024C 种植方案 |
| 机理 | 机理、推导、反演、标定 | 方程组与参数解 | 与实测吻合度 | 2023A 定日镜场 |

## 易混词辨析

- 影响因素：看是否要求未来数值——只给关系是回归，给未来是预测。
- 分类 vs 分组：看附件有没有标签列——有标签是判别，无标签需自行划分是聚类。
- 最优 vs 评价：看有没有可调整的决策变量与可行域——有是优化，没有只是排序。

## 选题定位（A/B/C）

- 难度排序：A > B ≥ C。
- A 题恒定"机理+优化"（力学、热传、动力学、微分方程），适合数学与推导强、答案相对收敛。
- B 题开放综合（社会、经济、管理、调度），方法杂、吃编程与工程思维，适合均衡型队伍。
- C 题数据经管（数据挖掘+机器学习+优化决策），数据量大、预处理重，适合编程与数据分析强的队伍。
- 必考题：优化（每年所有题均含优化模块）；近年趋势偏向双碳、数字经济、现代农业、智慧交通、先进制造。
- 官方评审标准（满分 100）：假设合理性 20、建模创造性 30、结果正确性 30、表述清晰性 20。

## 模型选型口诀

- 评价：无数据靠经验用 AHP；有数据要公正用熵权；比优劣排顺序用 TOPSIS；评等级很模糊用模糊综合评价；数据大求精准用机器学习。
- 优化：能小数、式子直 → 线性规划；必须整数 → 整数规划；选或不选 → 0-1 规划；平方乘积曲线变 → 非线性规划；又要赚钱又省钱 → 多目标规划；排列组合找最优 → 组合优化（遗传/粒子群/模拟退火）。
- 机理：找原因、析影响 → 因果归因；物理变、高精度仿真 → 微分方程机理；拆系统、理框架 → 结构机理分析；看反馈、长期宏观演化 → 系统动力学。

## 高分组合

- 少数据稳妥：AHP + TOPSIS。
- 多数据严谨：熵权法 + TOPSIS。
- 定性专属：AHP/熵权 + 模糊综合评价。
- 创新进阶：机器学习 + 传统算法对比验证；主观+客观博弈论组合赋权。
- 预测题至少对比 3 种模型（RMSE/MAE/MAPE/R² 交叉验证）；评价题至少 2 种方法对比（Spearman/Kendall 一致性）；优化题精确算法（MILP）+ 启发式（GA/PSO）对比收敛曲线与 Gap。

## 选型纪律

每道子问题最多两个独立模型体系（与根 SKILL 建模约束一致）；同机理不同精度的展开按一个模型族计数。候选集必须包含一个可运行的简单基线——基线不是用来交付的，是用来被超过的。选定后要用"本题数据条件下优于另外两个候选 + 更换合理设定后结论仍成立"的证据链说明"最优"，而不是一句结论。
